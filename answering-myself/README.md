# answering-myself — Codex 인계 패키지

## 바로 실행

`index.html` 파일을 브라우저에서 열면 됩니다. 별도 패키지 설치나 서버가 필요하지 않습니다.

질문 날짜는 한국 표준시(KST) 오전 5시에 전환됩니다.

## 포함 파일

- `index.html`: 반응형 인터랙티브 시연 프로토타입(HTML/CSS/JS 단일 파일)
- `PROJECT_SPEC.md`: 서비스 배경, 확정/제외 기능, 사용자 플로우, 수용 기준, 미결정 정책 및 Codex 요청문
- `README.md`: 실행 및 전달 안내

## 시연 범위

오늘 질문/작성, 이전 질문 읽기 전용, 연도·월 펼침/접기, 날짜 이동, 5개씩 페이지 탐색, 200자 초과 본문 펼침/접기, 모바일 메뉴.

모든 질문과 글은 **샘플 데이터**입니다. 글 등록은 브라우저 메모리에서만 작동하며 새로고침 시 사라집니다. 시연을 위해 샘플 과거 날짜를 포함합니다.

## 코덱스에 전달할 때

프로젝트 폴더를 작업 디렉터리로 열고 `PROJECT_SPEC.md`부터 읽도록 지시하세요. 실제 서비스 구현 전에는 문서의 '후속 결정 필요 항목'을 먼저 검토해야 합니다.
